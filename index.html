Лёгкая библиотека на Vanilla JS: масштабирование при наведении и плавное появление при прокрутке. Один импорт — и всё работает.

Начать Смотреть эффекты

Эффекты

Масштабирование

Наведите курсор — карточка плавно увеличится. Класс .jf-hover-scale

Плавное появление

Элементы проявляются при прокрутке через IntersectionObserver. Класс .jf-fade

Изоляция стилей

Все классы имеют префикс jf- и не конфликтуют с вашей вёрсткой.

Подключение

import { Jffect } from './jffect.js';

Jffect.init();

<div class="jf-hover-scale">Наведи на меня</div>
<div class="jf-fade">Появлюсь при прокрутке</div>

Контроль веса

Встроенный плагин Vite проверяет размер бандла: при превышении лимита сборка завершается с кодом 1.
